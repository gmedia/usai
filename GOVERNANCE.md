# Governance

Usai is maintained by the **Sakala maintainers**. Direction, contracts,
releases and the roadmap (`docs/ROADMAP.md`) are theirs.

The repository is hosted in the `gmedia` GitHub organization, which supports
the project (infrastructure, CI, funding of maintainer time). That support
does not steer the project: gmedia is a sponsor, not the author, and nothing
in this repository speaks in gmedia's name.

Published identities:

| What | Where |
|---|---|
| Source | https://github.com/gmedia/usai (hosting) |
| npm | `@sakaladev/usai`, `@sakaladev/create-usai` |
| Docker Hub | `sakaladev/usai` |
| Releases | GitHub releases of the repository above (binaries + checksums) |

Usai stays usable without Sakala or any other deployment platform
(`README.md` "Sakala ecosystem").
