# create-usai

Scaffolds a new [Usai](https://github.com/gmedia/usai) application.

```bash
pnpm dlx @sakaladev/create-usai my-app     # or: npm create @sakaladev/usai@latest my-app
cd my-app && pnpm install
usai dev
```

The `usai` binary comes from https://github.com/gmedia/usai/releases. Guide:
https://github.com/gmedia/usai/blob/main/docs/GUIDE.md. Developer preview.

Apache-2.0.
